Mit dieser Podcast-Website können Sie jeden Podcast abonnieren, indem Sie die URL des Podcast-Feeds in die Abonnieren-Leiste eingeben. Wenn Sie dann auf einen Podcast klicken, gelangen Sie zu den Podcast-Details mit einer Episodenliste. Klicken Sie einfach auf die jeweilige Episode, um sie anzuhören. Es werden auch die drei neuesten Episoden aller abonnierten Podcasts angezeigt. Hier sind zwei Beispiele für Podcast-Feeds:

https://feeds.megaphone.fm/FSI1483080183

https://workingdraft.de/feed/
Es gibt sowohl eine Version 0 mit HTML, JavaScript und CSS als auch eine Version 1 mit Express, Node.js und EJS.
